Iframe / OOPIF Stress Test

Generates a large number of iframes for stress-testing frame/process handling. "Sandboxed (opaque origin)" frames use sandbox without allow-same-origin, which gives each frame a unique opaque origin distinct from the embedder and from every sibling — Chromium's Site Isolation can put these in their own renderer process (see chrome://flags/#isolate-sandboxed-iframes), producing OOPIFs without any network dependency. "Real cross-origin" frames load actual third-party sites for genuine cross-site OOPIFs and are capped to avoid hammering external servers.
