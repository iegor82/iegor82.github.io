HTTP 404 Resource Test

Loads a variety of resource types from URLs under ./missing/ that are guaranteed not to exist. Every request below should resolve to a real HTTP 404 from the server — check the tables and the DevTools Network tab to confirm.

Loaded via static HTML markup

These use ordinary <link>, <script>, <img>, <video>, <audio>, <iframe>, <object> tags and CSS @font-face / background-image declarations written directly in the page source (see "View Source") — the browser requests them on its own, with no JavaScript triggering the fetch. The favicon and stylesheet <link> tags and the <script> tag are in <head> above; the rest are previewed below (expect broken-image icons / empty players).
